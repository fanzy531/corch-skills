# Translate Helper

## When to use

- Source text is in Japanese, English, Korean, etc.
- Target audience is Chinese-speaking community workers
- Need consistent translation of key terms across multiple articles

## Terminology consistency

For community-building content, these terms must be translated consistently:

| Source (EN/JP) | Chinese |
|---|---|
| community building / 社区営造 | 社区营造 |
| placemaking / まちづくり | 场所营造 / 地方创生 |
| participatory design | 参与式设计 |
| grassroots | 草根 / 基层 |
| civic engagement | 公众参与 |
| social innovation | 社会创新 |
| neighborhood | 邻里 / 街区 |
| local revitalization / 地方創生 | 地方创生 |
| resident-led / 住民主体 | 住民主导 |
| field survey / フィールド調査 | 田野调查 |

## Workflow

1. Receive source text (URL, PDF extract, or pasted text)
2. Identify source language
3. Translate to Chinese, apply terminology mapping
4. Preserve proper nouns (names, place names, org names) in original
5. Output: Chinese text with translator note
