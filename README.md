# corch-skills

Codex skills for the c-lab ecosystem.

## Skills

### corch-digest

Read, digest, and rewrite articles from URLs, output inline-styled HTML, and optionally publish to WordPress voice CPT (他山之石).

**Install:**
```
codex skill install fanzy531/corch-skills --path skills/corch-digest/SKILL.md
```

**Usage:**
- Provide a URL → get digested HTML + 导读 + metadata
- With `wp_site` params → auto-publish to WordPress

### corch-action (coming soon)

Parse structured markdown project documents and publish to WordPress action CPT (实践现场).
